## 1. Đã xác minh cài Git — 5 phút

Người học chạy:

```powershell
git --version
```

Đầu ra thực tế:

```text
git version 2.55.0.windows.5
```

**Đánh giá bước này: PASS.** Git CLI hoạt động. Chưa có bằng chứng về `clone`, `status`, `diff`, `add`, `commit`.

## 2. Tạo bản sao bằng git clone — 15 phút

Dùng **Windows Terminal / PowerShell**. Về thư mục cha nơi đang có `python-study`:

```powershell
cd D:\Project\Learn
git clone https://github.com/dvha85/coding-interview-university.git ciu-git-practice
```

Giải thích:

- `git clone` = tải/sao chép repository cùng lịch sử Git từ một địa chỉ remote.
- `ciu-git-practice` = tên thư mục **mới** chứa bản sao phục vụ thực hành.
- Clone **không** chỉnh sửa GitHub remote hoặc tệp ở `python-study`.

Nếu hiện lỗi thư mục đã tồn tại, mạng hoặc xác thực, không xóa/thay đổi thư mục; chép nguyên lỗi để xử lý.

Vào bản sao mới và kiểm tra:

```powershell
cd .\ciu-git-practice
git status
```

Thông thường clone sạch sẽ hiện đang ở nhánh chính (ví dụ `main`) và không có thay đổi cần commit. **Kết quả thực tế tùy repository; cần ghi lại, không nhận PASS trước khi chạy.**

## 3. Git status và diff — 20 phút

`repository` (repo) = một thư mục dự án mà Git quản lý phiên bản. `working tree` = các tệp làm việc hiện tại. Dùng Notepad mở tệp **đã được Git theo dõi** trong bản sao:

```powershell
notepad .\learning\lessons\W01-S3.md
```

Thêm một dòng cuối file:

```text
My first local Git change.
```

Lưu và đóng Notepad. Chạy:

```powershell
git status
git diff
```

Cần quan sát: `git status` báo tệp `modified` (đã chỉnh sửa), `git diff` cho biết dòng nào vừa được thêm (`+`). **Chỉ chỉnh trong thư mục `ciu-git-practice`, không phải repository gốc đang học.**

## 4. Git add và commit — 20 phút

`staging area` = vùng tạm chọn thay đổi cho bản ghi tiếp theo. Thực hiện:

```powershell
git add .\learning\lessons\W01-S3.md
git status
git diff --staged
git commit -m "docs: practice Git basics"
git status
git log -1 --oneline
```

- `git add` **không** tạo commit; nó chọn thay đổi đưa vào staging area.
- `git commit` ghi một snapshot vào **lịch sử Git cục bộ**.
- `git diff` xem thay đổi chưa stage; `git diff --staged` xem thay đổi đã stage.
- `git log -1 --oneline` xem bản ghi commit mới nhất.
- **Không chạy `git push` trong buổi này.** Commit cục bộ không tự được tải lên GitHub.

Nếu Git yêu cầu tên/email tác giả, ghi nhận thông báo và hỏi trợ giảng trước khi thiết lập. Không cần gửi địa chỉ email riêng trong chat.

## 5. Tiếng Anh công nghệ — 15 phút

| Từ | Nghĩa trong bài | Câu mẫu |
|---|---|---|
| clone | sao chép kho mã nguồn | Clone the repository. → Sao chép kho mã nguồn. |
| status | trạng thái | Check the status. → Kiểm tra trạng thái. |
| diff | phần khác biệt/thay đổi | Review the diff. → Xem lại phần khác biệt. |
| stage | đưa thay đổi vào vùng chuẩn bị commit | Stage the changes. → Đưa thay đổi vào vùng chuẩn bị lưu. |
| commit | lưu một bản ghi thay đổi | Commit the changes. → Lưu bản ghi thay đổi. |

**Đọc hiểu (dịch sang tiếng Việt):**

> Clone the repository. Check the status. Edit one file and review the diff. Stage your changes and create a commit.

Không cần viết prompt bằng tiếng Anh; ưu tiên đọc hiểu từ vựng công nghệ.
