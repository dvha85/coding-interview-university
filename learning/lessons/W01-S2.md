# W01-S2 — Cài đặt và chạy Python đầu tiên trên Windows 11 / Run your first Python program

[Giáo án W01-S1](W01-S1.md) · [Checklist W01](../../CHECKLIST.md#w01) · [Nhật ký](../LEARNING-LOG.md) · [Sổ từ vựng](../VOCABULARY.md)

**Môi trường người học xác nhận:** Windows 11 (21/10/2026). **Thời lượng tham khảo:** 90 phút. **Trạng thái:** đang chuẩn bị; **chưa xác nhận đã cài/chạy** Python hoặc VS Code.

## Mục tiêu

1. Xác định phiên bản Python đã cài hoặc cài Python 3 khi cần.
2. Mở Windows Terminal/PowerShell, chạy chương trình ở chế độ tương tác (`>>>`).
3. Tạo tệp `hello.py` bằng Visual Studio Code hoặc trình soạn thảo văn bản phù hợp, chạy tệp và so sánh đầu ra với dự đoán.
4. Hiểu nghĩa các từ `install`, `version`, `terminal`, `interpreter`, `script` và giải thích bằng tiếng Việt.

## 1. Kiểm tra Python có sẵn — 10 phút

- Trên Windows 11, nhấn `Win + X` → **Terminal**; không cần chế độ Administrator.
- Nhập lần lượt:

```powershell
python --version
py --version
```

- Nếu một trong hai lệnh hiện `Python 3.x.x`, ghi lại phiên bản và dùng lệnh tương ứng (`python` hoặc `py`) cho các bước tiếp theo.
- Nếu chưa cài hoặc lệnh không được nhận diện, chuyển mục 2. Nếu `python` mở Microsoft Store thay vì hiện phiên bản, đừng coi là đã cài thành công.
- **Bằng chứng:** chép nguyên dòng kết quả lệnh, không tự suy ra từ những ví dụ trong bài.

## 2. Cài Python khi cần — 15 phút

Theo tài liệu Python hiện hành, Windows có thể cài **Python Install Manager** từ [python.org/downloads](https://www.python.org/downloads/) hoặc Microsoft Store. Sau khi cài, mở lại Terminal và dùng `python` hoặc `py` để chạy Python; nếu chưa có runtime, trình quản lý có thể cài bản ổn định khi chạy lần đầu.

- Cài từ nguồn chính thức, không dùng gói cài đặt không rõ nguồn.
- Mở lại Terminal và xác nhận:

```powershell
python --version
```

- Nếu lệnh `python` bị lỗi nhưng `py` hoạt động, có thể dùng `py` thay thế trong buổi này. Nếu hai lệnh đều lỗi, chép nguyên thông báo để chẩn đoán, không tự đổi `PATH` khi chưa hiểu vấn đề.

Tham khảo: [Python — Using Python on Windows](https://docs.python.org/3/using/windows.html), mục Python install manager.

## 3. Chạy Python tương tác — 10 phút

Nhập `python` (hoặc `py`, nếu đó là lệnh hoạt động). Dấu nhắc `>>>` cho biết bạn đang ở trong **Python interpreter** (trình thông dịch Python):

```python
print("Hello, Python!")
print(3 * 5)
```

Đầu ra mong đợi:

```text
Hello, Python!
15
```

Gõ `exit()` rồi Enter để quay về Terminal.

**Quan trọng:** `python --version`, `python hello.py` là lệnh của Terminal; `print(...)` là lệnh Python nhập sau dấu `>>>` hoặc viết trong tệp `.py`.

## 4. Cài trình soạn thảo và chạy file .py — 25 phút

- Nếu chưa có, tải **Visual Studio Code** tại [code.visualstudio.com](https://code.visualstudio.com/). Mở mục Extensions và cài tiện ích mở rộng **Python** của Microsoft.
- Trong VS Code, chọn **File → Open Folder** và tạo/mở thư mục học, ví dụ `Documents\python-study`.
- Tạo tệp mới tên **hello.py** (đúng phần mở rộng `.py`) rồi nhập:

```python
print("Hello, Python!")
print(3 * 5)
```

- Lưu tệp bằng `Ctrl + S`.
- Chọn **Terminal → New Terminal** trong VS Code và nhập:

```powershell
python hello.py
```

  Nếu chỉ `py` chạy được, thử `py hello.py`. Đầu ra mong đợi vẫn là hai dòng `Hello, Python!` và `15`.
- Cách khác: chọn **Python: Select Interpreter** trong Command Palette (`Ctrl + Shift + P`) nếu cần, sau đó nhấn **Run Python File in Terminal** ở góc trên bên phải.

Nguồn: [VS Code — Running Python code](https://code.visualstudio.com/docs/python/run).

## 5. Thử một biến thể độc lập — 10 phút

Đổi dòng thứ hai thành `print(4 + 6)`. Trước khi chạy, ghi kết quả mình dự đoán. Chạy lại và so sánh với kết quả thực tế. Nếu không trùng, chép cả dự đoán lẫn kết quả để cùng phân tích.
